A checker that reads first

I wanted a check on my own case drafts. A model had already called a draft clean when the draft had invented a construction site. The job is one decision: publish or hold.

The decision I kept: the model does not get the files in the first message. It has to call read_file. If it says publish before both files were read, the code rejects that and sends it back. It cannot edit the note or the draft.

The limit I am leaving in: the faithful draft should publish. The note says Buy milk does not survive a restart, and the draft says the same thing. The second eval held it, and the reason said Buy milk is not in the note. Both files were read, so the code allowed the hold. I stopped rewriting the prompt.

The code also does not yet reject a reason that quotes a line the note does not contain. That check is in the spec. It is not in agent.py.

Cursor wrote the loop and this page with me. The hold and publish lines are from qwen2.5:7b on this machine. I checked them against the notes.
